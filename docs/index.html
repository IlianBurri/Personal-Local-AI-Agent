Multi-provider

Connect to OpenAI, Anthropic, or a local Ollama instance with a unified interface.

Local-first

Clean UI

A calm, focused interface built for writing and conversation — no distractions.

Clone & run

git clone https://github.com/IlianBurri/arca.git
cd arca
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m ui.main
