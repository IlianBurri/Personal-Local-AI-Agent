Desktop AI agent that adapts to any LLM backend

Configure providers, switch models, and interact with your preferred LLM — locally or hosted. Built with Python + PyQt6 for a focused, offline-capable experience.

Small interactive preview of the UI and workflows.

Multi-backend

Switch between OpenAI, Anthropic, or a local Ollama instance without changing code.

Streaming & memory

Multi-turn memory, editable system prompts, and token-by-token streaming in the UI.

Tools & safety

Built-in file, shell (with confirmation), and web search tools with clear prompts.

Clone & run

git clone https://github.com/IlianBurri/Personal-Local-AI-Agent.git
cd Personal-Local-AI-Agent
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m ui.main
