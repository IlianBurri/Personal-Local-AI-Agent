what it does
01

Any provider

Anthropic, OpenAI, or a local Ollama instance. Configured once, switchable anytime from the sidebar dropdown.

02

Stays local

API keys live in ~/.config/arca/config.json — never hardcoded, never sent anywhere they shouldn't go.

03

Streaming output

Responses arrive token by token. No waiting for the full reply — the interface stays live as the model writes.

04

Focused UI

A calm, distraction-free layout. Sidebar for history, centre for chat, right panel for system prompt and controls.

Clone & run

Run from source in a virtual environment.

git clone https://github.com/IlianBurri/arca.git
cd arca
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m ui.main
