Features
01

Multi-provider

Switch between OpenAI, Anthropic, and local Ollama models from one unified interface.

02

Local-first

Run models entirely on your machine via Ollama. Your data never leaves unless you choose a cloud provider.

03

Clean UI

A focused, distraction-free interface built for writing, coding, and conversation — nothing more.

04

Open source

MIT licensed. Clone it, fork it, extend it. Built with Python and PyQt6 — no Electron, no bloat.

Install

Download a release

Grab the latest binary for your platform from the GitHub releases page. No Python required.

Download latest release
or

Clone & run

Run from source with Python 3.10+. Ideal if you want to hack on it.

git clone https://github.com/IlianBurri/arca.git
cd arca
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m ui.main
